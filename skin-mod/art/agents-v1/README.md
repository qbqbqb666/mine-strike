# 探员皮肤第一版素材

按用户选定的 CT1/3/4/6/8、T1/3/4/5/7 制作。CT6 为 Ricksaw。

本目录仅供外观预览，未接入角色选择、未部署到 PCL，未修改模型或碰撞及爆头判定。

10 张贴图均为 512×512 RGBA，采用 Java 版原生宽臂 64×64 UV 布局的八倍分辨率，基础层不透明、外层透明。后续作为模组本地纹理接入，不用于直接上传原版账号皮肤。模型比例读取现有 player-shape-mesh.json：方头 55%，身体及四肢宽厚 65%、纵向 85%。预览是读取最终 PNG 的离线几何渲染，不是游戏截图；装备遮挡和动作仍需以后在游戏中验收。

创作方式：内置 imagegen 根据 Valve 官方宣传图和固定 UV 模板分别绘制。原始图的像素边界、透明边缘和 UV 对齐需经过技术整理；源图、生成提示词和转换信息见 manifest.json。成品为适配 Minecraft 的再绘制，非 Valve 模型原始贴图提取。

官方参考图未展示的背面属于补全设计。头盔、帽子、头发和耳机均为贴图表现，没有增加立体配件。UV 整理脚本 pack_uv.py 对齐贴图条带，并由可靠的右臂／左腿区域镜像补全另一侧，因此两侧装备细节有对称处理。预览通过不表示已完成游戏验收。

overview.png 是十人正面总览，ct-preview.png、t-preview.png 分别提供各角色的正面、斜侧、侧面与背面。manifest.json 保存角色编号、官方参考链接、内置 imagegen 完整提示词、原始生成图路径、UV 整理记录、SHA256 和文件检查结果。

重新预览：使用带 Pillow/NumPy 的 Python 执行 `render_preview.py`。该脚本只读取皮肤并输出两张预览，不修改游戏文件。
